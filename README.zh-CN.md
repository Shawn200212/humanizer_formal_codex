# HumanizerSkill — 保留证据约束的中英文学术修订

[English](README.md) | **中文**

Humanizer 用于修订中英文论文文本，同时锁定事实、数字、引文、原话、不确定性与主张强度。
它会删除空泛模板语并提升论证可见性，但拒绝 AI 检测规避、证据捏造与作者身份洗白。

可执行 Skill 与内部评测材料位于私有仓库 `Shawn200212/HumanizerSkill-core`。本公开仓库只发布
方法边界、CC0 书目清单、汇总指标与早停曲线；不发布 Skill 指令、论文摘要/全文、诊断模型、
隐藏测试材料或用户稿件。

## 语料快照

- 共 200 条 OpenAlex 论文记录：中文 100、英文 100。
- 按论文固定划分：训练 140、开发 30、测试 30；每种语言均为 70/15/15。
- 182 篇期刊论文、18 篇会议论文，来自 200 个不同来源。
- 私有 core 仅保存元数据与摘要；未下载或再分发论文 PDF/全文。
- 该集合可复现且做了领域平衡，但不是“全网所有主流来源”的穷举。

OpenAlex 元数据采用 CC0；位置级许可证字段只能用于发现，不能替代逐篇版权审核。因此公开的
`metadata_manifest.csv` 只含书目信息与哈希，不含摘要或全文。

## 早停结果

训练组件只是一个窄范围的“合成空泛句诊断器”，不是 AI 检测器，也不是 Skill 本身。开发集损失
在第 365 轮达到最低；按预先设定的 50 轮 patience 继续观察后于第 415 轮停止，并恢复第 365 轮
检查点，再对固定测试集评估一次。

| 固定测试指标 | 数值 |
|---|---:|
| 样本数 | 334 |
| 平衡准确率 | 0.9701 |
| 真实摘要句 F1 | 0.9691 |
| 合成空泛句 F1 | 0.9709 |
| 二元交叉熵 | 0.5028 |

这些数字仅适用于当前合成任务，不能解释为事实正确率、作者身份、检测规避效果、整体修订质量或
论文录用率。

另有两例隔离中英文对抗测试通过，详见 `reports/bilingual-forward-test.md`；其样本量只有 2，
只能证明当前合同冒烟测试通过，不能声称普遍泛化。
